# Design System: Soft Focus Editorial

Direction chosen 2026-11-17 for the build on placeholder content. The brand name is settled as Tate Fine Art Photography (2026-11-18; the wordmark sets "Tate" in Bodoni Moda roman and "Fine Art Photography" in its italic, in Dusk, drawn at optical size 24 by `scripts/build-wordmark.mjs`). One answer from the client can still move it: whether she would rather have a dark site (the site is light only since 2026-11-18; the dark tokens are still in the code, so bringing dark back is a small change). The CSS wins if this file and the code disagree: tokens live in `brand/brand.config.json`, written into `src/styles/globals.css` by `npm run apply-brand`; the site's own layer is `src/styles/erin.css`.

## 1. Overview

**Creative North Star: everything comes into focus.** A fine-art portrait portfolio that feels like a printed art book: warm paper, a large editorial serif, photos given room, and motion that behaves like a lens pulling focus.

- **Light only** (2026-11-18, rule 3). Warm paper is the one ground; there is no theme toggle and the system dark setting is ignored. The dark column below is kept for reference and for the shared dark test suites.
- **No polish-layer chrome.** No brand stripe, no card lift, no tinted bands around photos. Sections separate by space and hairline rules.
- **Square corners.** Radius 0 on photos, buttons and fields.
- **One left edge, one row of chrome** (2026-11-17; the boutique bar since 2026-11-20). The header has no eyebrow strip; its one row uses the page gutter so the wordmark lines up with every heading below it. Content bands all sit on paper: the starter's paper-soft cadence, sunburst ornaments and testimonial glow are switched off in `src/styles/erin.css`, and sections part with a content-width hairline. The footer is "the boutique close" (2026-11-20): its index, wordmark and small print sit on the same content column and gutter as the header.

## 3. Typography

- **The "Couture" pairing (chosen by Nathan 2026-11-20; replaced Bodoni Moda and Jost).** Self-hosted from `@fontsource-variable/bodoni-moda` (the `opsz` files: weight and optical size 6 to 96, roman and a true italic) and `@fontsource-variable/jost`.
- **Display: Bodoni Moda** (400, roman and italic), the high-contrast Didone. `font-optical-sizing: auto` (`erin.css`) lets the size pick the cut: titles get the fine fashion hairlines, small uses the sturdier small-size cut. Story titles and page heads run very large and tight (`line-height: 1`, `--display-track-lg` -0.015em); small display uses (the header place block, 16px) open up a little (`--display-track-sm` 0.01em). Bodoni sets about a third wider than Bodoni Moda did, so the knockout title (8vw), the footer "Tate" (1.86em per word) and the opening were resized for it. Italic "turn" words stay in true Bodoni italic. The display face is never used for running text: below about 18px everything is Jost.
- **Body and UI: Jost Variable**, the Futura-like geometric sans. Credits, captions and the nav set small, uppercase, tracked (0.14em) so they read like a magazine masthead; reading text is Jost too.
- **Metric fallbacks** for both faces (`src/styles/font-fallbacks.css`, written by `npm run font-fallback:variable`): Georgia and Times (with their Linux twins) stand in for Bodoni, Arial (Liberation Sans, Arimo) for Jost, scaled so lines break where the real faces will.
- Numbers in credits and EXIF use tabular figures.

## 4. Elevation

Flat. Nothing floats except the lightbox and the phone menu. Depth comes from photos, not shadows.

## 6. Do's and Don'ts

Motion: slow optical easing `cubic-bezier(0.22, 1, 0.36, 1)`, 700 to 1200ms for focus pulls, 300ms for UI. Scrolling stays native (rule 5). Every effect has a reduced-motion and a touch fallback, and hidden start states sit under `html.motion` so the page reads without JavaScript. The site plan's interactions live in `src/styles/erin-motion.css`: a first-visit loader (`FirstVisitLoader.astro`: the name pulls into focus and the curtain lifts in 1.1s, once per device, never under reduced motion or with storage blocked; it hides nothing underneath), the footer's rolling credits. The header and phone menu keep their motion in `src/styles/chrome-header.css` (the dimmed nav, the drop and the rolling lines). The story page's film has its own motion (Story page, above).

**Do**

- Let photos run full bleed or with generous margins; keep captions small.
- Credit every person on a story, linked where they have a page.
- Use placeholder images that read as placeholders until originals arrive.

**Don't**

- Don't frame photos in cards, shadows or rounded corners.
- Don't use a script font, blush pink, or wedding-template copy.
- Don't distort photos with shaders beyond the hero's one focus effect.
- Don't write an em-dash in public copy.
